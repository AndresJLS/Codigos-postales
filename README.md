# Buscador de codigos postales

## Descripción general
Ventana que usa un archivo.csv el cual almacena los codigos postales de hermosillo con sus colonias, el sistema busca el codigo postal que el usuario pone en la ventana principal y luego suelta una lista de todas las colonias pertenecientes a ese codigo postal.


## Lenguajes y tecnologias
-Java

-Se usa NetBeans para abrirlo pero tambien puede usar el IDE de su eleccion


## Requerimientos
- Java instalado (obligatorio por que yo digo)

## Inicializar el programa
-En el caso de descargar el código, el archivo comprimido debe ser tipo zip para hacer mas facil su importacion a NB
